# Draba Resources

Draba Resources is a client-side Fabric mod for Minecraft 26.1.2. It keeps the network's managed visual packs enabled in a stable order and presents the appropriate server identity in the client interface.

The third-party resource packs referenced by `ManagedPackPolicy` are not bundled here. They must be installed separately by the modpack distributor.

## Build

```bash
./gradlew clean build
```
